## 1. 背景

參考專案 [`bstocks-lp-assistant`](../reference/SOURCE.md) 用期權視角評估代幣化股票 LP 的風險調整收益，數學模型完善，但有三個限制：

1. 只看 BSC 上的 bStock，看不到 Solana 等其他鏈與其他發行商。
2. 無法比較同一檔股票在不同鏈、不同池子的收益。
3. 池子資料依賴 `baw`，必須登入錢包才能運作。

## 2. 目標

做一個**唯讀**的代幣化股票 LP 比較工具：對同一檔美股，列出它在各鏈、各發行商、各費率階梯的 LP 池子，用一致的方法比較風險調整後的收益，並提供資金配比建議。

## 3. 使用者與使用情境

- **定位**：個人工具，公開唯讀。不做帳號、不做登入，任何人都能瀏覽。
- **主要使用者**：開發者本人。
- **其他訪客**：可以瀏覽、在自己的瀏覽器裡建立關注清單。
- **使用情境**：打開網頁，看自己關注的股票目前哪條鏈、哪個池子的淨收益最好；順便看市場上淨收益最高的是哪些股票。
- 若之後確認有流量，再評估是否升級為正式產品（見 §9）。

**與參考專案的定位差異**

| | 參考專案 | 本專案 |
|---|---|---|
| 定位 | Agent 互動工具 | 資料匯集站 |
| 運作方式 | 使用者提問時即時抓取、計算 | 排程定期抓取、計算並儲存 |
| 介面 | Claude 對話、命令列 | 只有網頁 |
| 與錢包的關係 | 讀取持倉、交給錢包執行 | 完全不碰 |

因此只移植參考專案的數學模型與過濾規則，不移植其互動流程。未來需要依使用者輸入計算的功能（資金配比、區間試算），須在瀏覽器端計算或事先算好，因為伺服器只提供靜態檔案。

## 4. 功能需求

### F1. 代幣與池子收錄
- 收錄幣安清單上的 bStock（BSC）與 xStocks（Solana、BSC），以及 Robinhood 官方清單上的股票代幣（Robinhood Chain）。
- **只收錄官方清單上的代幣**（以合約地址比對），第三方發行的同名代幣、槓桿代幣（如 `AAPLx3L`）一律不收錄。
- 以美股標的對齊不同鏈、不同發行商的代幣（`TSLAB`、`TSLAx`、Robinhood 的 `TSLA`）。有 ISIN 時優先用 ISIN 對齊，避免同代號不同股票類別混淆。
- 同一檔股票在同一條鏈上可能有多個發行商，兩者都要列出。

### F2. 收益與風險評估
- 沿用參考專案的量化方法：Yang-Zhang 波動率、相對波動率（非穩定幣配對）、損益平衡波動率與 Richness 評級、集中流動性區間與存活機率。
- 沿用參考專案的過濾規則：TVL 下限、異常費率、同標的 APY 離群值。
- 時間加權收益（7 天 / 30 天），並依 APY 的穩定度給予折價。
- **跨池比較必須用同一套 APY 算法**，不能直接混用各資料源自己報的 APY。
- **歷史資料不足的池子**：可用的歷史資料少於 7 天時，標示「資料僅 N 天」，**不參與「最佳淨收益」的選取與排名**，但仍列在展開的卡片中。
- **排除 V4 架構的池子（所有鏈）**：Uniswap V4 與 PancakeSwap Infinity（含 CLMM 與 Bin 池）一律不收錄、不顯示、不計算。這類池子可掛載 hook（池子建立者自訂的合約），可能未經審計，且公開資料源無法得知池子掛載了哪個 hook。此規則沿用參考專案的 V4 封鎖原則；除非開發者明確同意，否則不開發 V4 相關功能。計算方法說明中須註明已排除這兩類池子。
- **費率無法取得的池子**（例如動態費率池）：無法用一致的公式估算 APY，標示「無法計算」，不參與排名。

### F3. 比較視圖
- 跨鏈：同一檔股票在各鏈的收益、TVL、交易量。
- 跨發行商：同一檔股票的不同發行商代幣。
- 跨費率階梯：同一 DEX 同一交易對的不同費率池，預設只顯示最佳的一個，可展開查看其他。

### F4. 資金配比建議
- 兩種模式：安全型（依 TVL 深度分配）與進取型（依收益最佳化，考慮自我稀釋）。
- 可用滑桿在兩者之間調整。
- 細節待討論，見 §8。

### F5. 報價資產分級與自選報價代幣
池子依「另一邊的資產」分三級：

| 級別 | 內容 | 處理方式 |
|---|---|---|
| 核心 | 穩定幣、原生幣（WBNB、SOL）、其他股票代幣 | 自動納入比較 |
| 自選報價代幣 | 開發者指定的代幣（例如牛来） | 納入比較，加上標籤 |
| 其他 | 其餘代幣 | 不顯示、不參與比較，但保留資料 |

- 自選報價代幣以**合約地址**指定，不用名稱（同名仿冒幣很多）。
- 名單改由設定檔管理，修改不需要改程式。
- 優先做「股票 × 自選報價代幣」的池子（例如 `QQQB/牛来`）。
- 純自選報價代幣池（例如 `牛来/USDT`）另開「自選池」頁面，不混進股票比較；排在後面的版本。

> 命名說明：「自選報價代幣」（F5，池子另一邊的資產）與「關注股票」（F6，使用者關注的股票）是兩件不同的事，文件與程式碼中不要混用「自選」一詞。

### F6. 單頁儀表板

公開、唯讀、單一頁面，不需要導覽列。由上到下三個區塊：

| 區塊 | 內容 | 預設排序 | 資料存放 |
|---|---|---|---|
| **我的關注** | 訪客用 ☆ 加入的股票 | 24h 交易量（可切換成淨收益） | 訪客自己的瀏覽器 |
| **市場收益排行** | 全部股票 | 最佳淨收益 | 伺服器產生的資料 |
| **Dev's Pick** | 開發者挑選的股票，可附一句短評 | 開發者自訂 | 伺服器上的設定檔 |

**股票卡片**（三個區塊共用同一種卡片）
- 收合時：股票代號、24h 總交易量、**最佳淨收益**、該收益所在的鏈與池子、☆ 按鈕。
- 展開時：列出該股票各鏈、各發行商、各 DEX 的池子（TVL、交易量、原始 APY、淨收益）。同一 DEX 同一交易對的其他費率階梯預設摺疊。
- 每個池子附上**前往該 DEX 池子頁面的連結**（PancakeSwap、Raydium、Orca 等），作為看完數字後的下一步。
- 每個代幣顯示**合約地址**（可複製）與**區塊瀏覽器連結**（BscScan、Solscan），方便操作前核對、避開仿冒代幣。
- **最佳淨收益**的定義：通過過濾條件（F2）的池子中，「7 天平均 APY 扣掉預估無常損失」後的最高值。**不使用原始 APY 的最高值**，避免小池子或單日暴衝誤導排序。

**其他要求**
- 「我的關注」為空時，顯示提示（例如「點 ☆ 把股票加到這裡」）。
- 「我的關注」存在瀏覽器，不跨裝置同步，清除瀏覽器資料後會消失；這是已知限制。
- Dev's Pick 放在最下方，不干擾其他訪客。
- 每個數字都要附上免責聲明（沿用參考專案的 DYOR 原則）。
- 頁面底部提供**計算方法說明**：淨收益如何計算、哪些池子被過濾及原因、估算的已知限制（CLMM 為粗估、不含挖礦獎勵、回補期間 TVL 為近似值）。內容可改寫自參考專案的 `MODEL.md`。
- 加上不需 cookie 的流量統計（例如 Cloudflare Web Analytics），作為日後是否升級產品的判斷依據。

## 5. 非功能需求

| 項目 | 要求 |
|---|---|
| 安全 | 伺服器不存放任何私鑰、助記詞或錢包登入憑證；沒有任何交易功能 |
| 可用性 | 24 小時在線，部署於雲端 VPS；核心功能不得依賴任何需要人工維護的元件（例如需手動登入的 session） |
| 資料新鮮度 | 每 15~60 分鐘更新一次；任何資料來源中斷時，網頁照常運作，並標示該資料的最後更新時間 |
| 外部請求 | 訪客瀏覽不會直接觸發外部 API 請求 |
| 伺服器寫入 | 網頁沒有任何寫入伺服器的功能；訪客的操作（☆ 關注）只存在訪客的瀏覽器 |
| 裝置 | 支援手機與桌機（響應式排版），手機上不需要橫向捲動 |
| 語言 | 第一版只做繁體中文。**預留多語系銜接點**：介面文字一律集中在語系檔、不寫死在元件裡；數字、金額、日期依語系格式化，第二版加英文時只需新增語系檔 |
| 可維護性 | 改計算公式、換資料源、加新鏈，彼此不互相影響 |
| 部署 | 使用者既有的 VPS + 網域，前面加 Cloudflare |
| 授權 | 移植自參考專案的程式碼保留 MIT 版權聲明 |

| 2026-10-23 | 只收錄官方清單上的代幣 | 排除仿冒、第三方、槓桿代幣 |
| 2026-10-23 | USDG（Paxos Global Dollar）視為穩定幣，加入 Robinhood Chain 與 Solana 的穩定幣清單 | Robinhood 主要報價幣，不納入會少掉大量股票池；地址已與 Paxos 官方文件核對 |
| 2026-10-23 | 第一版只做繁體中文，預留多語系銜接點，第二版再加英文 | 先求簡單；文字集中管理，日後加語言不需改元件 |
| 2026-10-23 | 只做網頁，不做命令列或 Claude 對話的查詢介面 | 本專案是資料匯集站，與參考專案的 Agent 互動定位不同 |
| 2026-10-23 | 「我的關注」存在訪客瀏覽器，伺服器不提供任何寫入功能 | 不需要後端 API 與身份驗證，伺服器維持只提供靜態資料 |
| 2026-10-23 | 卡片外層顯示「最佳淨收益」，不顯示原始 APY 最高值 | 原始 APY 易被小池子、單日暴衝、未扣無常損失誤導 |
| 2026-10-23 | 若接入 baw，只在家中設備搭配空帳號執行，結果推送到 VPS；VPS 上不放錢包憑證 | 降低憑證暴露 |
| 2026-10-23 | 家中設備的資料只是雲端的「補充資料源」，雲端永遠不依賴它；家中設備關機或 session 過期時，雲端只用公開資料，baw 欄位顯示最後更新時間，過期則改用估算值 | 維持 24 小時可用性；避免兩端互相依賴造成維護困難 |
| 2026-10-23 | 家中設備與雲端之間的傳輸層：優先使用 **Cloudflare R2**，用不習慣再改用 GitHub 私有 repo | R2 專為存放檔案設計、兩端不需要 git、免費額度遠超用量；GitHub 為熟悉的備案 |
| 2026-10-23 | 傳輸層的憑證只能讀寫該 bucket / repo，不能存取錢包；R2 token 限定單一 bucket，家中只寫、VPS 只讀 | 憑證外洩時影響範圍最小 |

## 9. 未來規劃（不在目前範圍）

**第二版候選**
- **通知提醒**（優先）：關注的股票最佳淨收益超過門檻，或持有的池子淨收益轉負時，透過 Telegram 等管道通知。排程本來就 24 小時運行，且符合個人工具定位。
- **淨收益歷史走勢圖**：展開卡片時顯示該池子 30 天的淨收益變化。
- **跨發行商比價**：同一標的不同發行商代幣（如 TSLAB、TSLAx）相對真實股價的溢價/折價。
- **英文介面**。
- §3.5 的延後項目：F4 資金配比與滑桿、區間試算、自選池頁面、baw 補充來源。

**依網站流量決定是否進行**
- 帳號登入、關注清單跨裝置同步
- 商用化評估（法律責任、流量成本、客服）
